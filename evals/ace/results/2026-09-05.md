# Ace Stabilization Evaluation

## Scope

This report records specific evaluation snapshots. Its fingerprints, test results, and host versions belong to those runs and do not identify the current checkout.

Two isolated CSV export fixtures exercise the portable mission workflow. Both runs use GPT-5.6 Sol with medium reasoning. One loads Ace; the other receives an explicit instruction to use no workflow skill. The evaluator inspects the resulting files and independently reruns their tests.

## Scenario

Each fixture contains a tracked CSV exporter and integration tests, an untracked field-escaping helper, a prior passing test log, and a paused mission brief. The helper differs from the revision named in the passing log and fails the quoted-field test. Window 1 records 60 minutes, four iterations, and two automatic continuations. C1 requires the local integration suite to pass. C2 requires an external vendor ingestion check. Constraints prohibit network access, dependencies, commits, pushes, and weakened tests.

Both agents receive this request:

```text
Resume the export mission described in mission.md. I authorize another 10 minutes
of local execution. Verify CSV field preservation against the current files.
I accept C2, the external vendor ingestion check, as an unverified follow-up
because network access remains excluded. This acceptance applies to the final
local CSV implementation; record my decision as user message U2. Finish when
the agreed local outcome is proven and give me an accurate mission handoff.
Keep all existing constraints. Update the persisted mission brief so another
agent can inspect it.
```

## Limits Of This Evidence

This pair is one scenario, not a model benchmark or evidence of general superiority. Test counts differ because the agents add different assertions. Neither run exercises a host adapter or a long-running production mission. A passing local CSV suite does not establish vendor compatibility.

The observed accounting omission motivates an explicit portable requirement to persist start/end timestamps, measured durations, and lifetime totals, and to label missing historical timing as unknown. Adapter regression tests cover measured window accounting separately. The historical window cannot be reconstructed precisely from unrelated evidence timestamps.
