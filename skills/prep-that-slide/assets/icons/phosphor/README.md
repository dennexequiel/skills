# Phosphor preview icons

Regular SVGs from [Phosphor Icons](https://github.com/phosphor-icons/core), distributed under the included MIT license. These assets support the preset samples. Phosphor regular is the default family when icons help identify content; a user can choose another family or an icon-free deck.

The bundled set includes chart-line-up, check-circle, chart-bar, list-checks, magnifying-glass and calendar-blank. [Source records](sources.json) pin the additional four assets to an upstream commit and record their hashes. The original two assets retain their upstream source and license attribution here.
